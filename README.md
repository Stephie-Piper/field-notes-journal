# Field Notes — Research Journal

A responsive, offline-first qualitative dissertation journal. The public repository contains only the application interface. Personal journal content is stored separately in a private Supabase row protected by authentication and row-level security.

## Install on iPhone

Open the published site in Safari, tap **Share**, choose **Add to Home Screen**, keep **Open as Web App** enabled if offered, then tap **Add**.

Use the same email and password on MacBook and iPhone. Edits save to the device first and synchronise automatically when online.

**Information governance:** do not enter identifiable patient, colleague, station, service-user or incident details.
